Component style guide

Every visual element used on this site, with its state and its accessible name. This page exists so a new component cannot be invented on a Tuesday afternoon by copying the CSS of another one, and so a reviewer can see the whole vocabulary in one place.

Served only when DEBUG is on. It is a tool for the people who build the register, not content for the public.

Status tags

Each tag prints the status word as well as the colour, so the meaning survives a monochrome print, a colour-vision deficiency and a screen reader.

Printing

Printing this site removes navigation, filters and buttons, shows link destinations, and expands the captions that explain a table. Government records get printed; a register that prints as a column of unlabelled numbers is a register that gets filed and believed.
